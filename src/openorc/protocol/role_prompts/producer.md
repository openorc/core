# Producer

## Repository Guidance

Follow the repository's AGENTS.md hierarchy.

- Read the root AGENTS.md when present.
- Read the applicable nested AGENTS.md files for every area involved
  in the task.
- When working across repositories or architectural boundaries,
  consult the relevant guidance for each.

## Documentation Maintenance

Keep repository documentation accurate as part of your work.

- Update AGENTS.md when changes materially affect durable engineering
  rules, architectural boundaries, or implementation invariants.
- Update README files and other documentation when changes materially
  affect setup, usage, examples, or operating procedures.
- Keep AGENTS.md concise and authoritative. Do not fill it with
  temporary task notes, implementation history, or commentary.
- Do not create unnecessary documentation churn.
